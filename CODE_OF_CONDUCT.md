# Code of Conduct

Astrolune is an open research project. Keep participation welcoming,
constructive and technically rigorous. Treat people with respect, assume good
faith, and focus criticism on ideas, code and evidence rather than individuals.

Harassment, discrimination, personal attacks, deliberate disruption, doxxing,
and publishing private information without consent are not acceptable.

Report concerns privately to the maintainers through the contact path in
[SECURITY.md](SECURITY.md). Maintainers may edit or remove content, restrict
participation, or ban behavior that violates this code.

This code applies in issues, pull requests, discussions, reviews, and project
events hosted by or on behalf of Astrolune.

Adapted from the Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
